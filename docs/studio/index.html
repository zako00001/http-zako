02 / 发布网站

四步更新全站

GitHub 就是你的管理员钥匙。别人即使打开这个工作台，也没有权限修改仓库，因此无法改变全站内容。

  1. 复制发布内容点击下面的黑色按钮。
  2. 打开 GitHub 更新页如果提示登录，就登录你的 GitHub 账号。
  3. 替换旧内容在编辑框里按 Ctrl+A，再按 Ctrl+V。
  4. 确认发布点击绿色的“Commit changes”，等待约 1–3 分钟。
